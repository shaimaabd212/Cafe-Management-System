# Menu photos

Put a photo of each menu item in this folder. The menu and cart pages pick it up by name;
until a photo is here, the item shows an empty arch with the Riwaq logo as a placeholder.

- File name = the item's English name in lower case, spaces → `-`.
- Type: `.jpg`, `.png` or `.webp` (looked for in that order).
- Shape: portrait works best (about 400 × 500 px, item in the middle); it is cropped to the arch shape on the menu.
